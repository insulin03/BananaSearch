# 题库书写规范

这份文档说明「什么样的文件能被香蕉做题导入」，以及怎么写才不会被跳过。

按这里的格式写，程序会自动把文件拆成一道一道的题、自动判断题型、自动把答案里的字母还原成选项原文。

## 一、支持哪些文件

- **`.txt`**：手打、从别处复制粘贴、聊天记录整理，按行解析，字段式。
- **`.docx`**：老师发的题库、自己排版的题库，正文按 txt 规则，文档里的表格按表格规则。
- **`.xlsx`**：一人一行最省事，首行当表头，一行一题。
- **`.csv`**：从 Excel「另存为 CSV」或从数据库导出，规则同 xlsx。
- **`.json` / `.jsonl`**：开源数据集、程序生成，字段自适应，多种别名都认。

补充三条：

- 单个文件上限 20 MB，超过会被拒绝，这是为了避免误选整个文件夹的压缩包。
- 一次可以选多个文件，每个文件单独成为一批。
- 导入后会生成一个「批次」，批次是后面管理题库的最小单位。

## 三、五条通用约定

所有格式都适用这五条。

1. 一个问题一条记录。程序不会把两题合并，也不会把一条拆成两条；只有 txt 和 docx 的「空行或 `---` 分隔」是拆分依据。
2. 答案必填。没有答案的题会被跳过，并在导入结果里报告「第 N 条缺少答案」。
3. 题型可以不写。不写时程序自动判断，见第八节；写了就以你写的为准。
4. 答案可以写字母，也可以写原文。选择题写 `A`、`ABC`、`A、C` 都行，程序会去选项里找对应原文，界面只显示原文内容，不显示字母；找不到对应选项时才退化成显示字母本身。
5. 中英文标点、全角半角都兼容。`：` 与 `:`、`，` 与 `,`、`（` 与 `(` 都认。

还有一个新手最容易踩的坑：文件开头可以有一行标题，但标题后面必须空一行。解析器是按「空行分隔题目」的，标题如果紧贴第一题，会被当成第一题题干的一部分，预览里就会看到标题和题干挤在一起。Word 和 txt 都一样，空一行即可。

## 四、TXT 格式

最小结构是这样，字段之间空行或不空行都可以，靠字段关键字区分：

```
<题干>

A. <选项一>
B. <选项二>
C. <选项三>
答案: <答案>
解析: <可选，可不写>
```

规则如下。

- 题目之间用一个空行分隔，或者用单独一行 `---` 分隔，两者等价，可以混用。
- 题干前面可以有 `题目:`、`题干:`、`Q:`，也可以完全不加。
- 题干前面的序号会被自动去掉，`1.`、`2、`、`(3)` 都认。
- 选项行以 `A.`、`A、`、`A．`、`A)`、`(A)` 开头，A 到 H 最多 8 个选项。
- 答案行以 `答案:`、`答案：`、`A:`、`ANSWER:` 开头。
- 解析行以 `解析:`、`分析:`、`说明:` 开头，可选，不参与匹配，只在预览里显示。
- 一行写不下就换行。题干、选项、答案、解析都能跨行，只有「下一个字段关键字」或「空行 / `---`」才会结束当前字段。

一个完整的例子，五种题型各一道：

```
1. 下列哪一项属于计算机科学与技术专业的专业核心课程？
A. 大学英语
B. 数据结构
C. 思想道德修养与法律基础
D. 体育
答案: B
解析: 数据结构是本专业的专业核心课，其余为通识课。

2. 下列属于面向对象三大特性的有？
A. 封装
B. 继承
C. 多态
D. 编译
答案: ABC

3. 计算机科学与技术专业专升本学生最低毕业学分是 81 学分。
答案: 对

4. 请简述 TCP 三次握手的过程。
答案: 客户端发送 SYN；服务端回复 SYN+ACK；客户端再发送 ACK，连接建立。

5. 二叉树的遍历方式有____、____、____三种。
答案: 前序遍历|中序遍历|后序遍历
```

判断题的答案可以写这些词，都算「对」：`对`、`正确`、`√`、`T`、`True`、`是`；都算「错」：`错`、`错误`、`×`、`F`、`False`、`否`。

两个小技巧。从 Word 复制过来时，常见的「第一题」「一、」这类行会被当成题干，导入后到预览里检查一遍即可。题干里含「下列」再加 4 个选项的题，几乎都能自动判成单选；多选记得答案写多个字母，比如 `ABD`。

## 五、Excel / CSV 格式

第一行必须是表头，从第二行开始一行一题。列的顺序无所谓，程序靠列名认。

- **题干**：`题目`、`题干`、`问题`、`question`、`stem`、`q`。
- **选项**：三种写法都行，拆成 `A` 到 `H` 多列，或列名写 `选项A` 到 `选项H`，或只给一列 `选项` 并用竖线把选项串起来。
- **答案**：`答案`、`正确答案`、`answer`、`key`。
- **题型**：`题型`、`类型`、`type`，可选。
- **解析**：`解析`、`分析`、`analysis`，可选。
- **序号**：`序号`、`编号`、`id`，可选，会被忽略。

举个例子，表头写成这样，下面三行就是三道题：

| 题目 | 选项A | 选项B | 选项C | 选项D | 答案 | 题型 |
|---|---|---|---|---|---|---|
| 下列属于面向对象特性的有？ | 封装 | 继承 | 多态 | 编译 | ABC | 多选 |
| 最低毕业学分是 81 学分。 |  |  |  |  | 对 | 判断 |
| 请简述三次握手的过程。 |  |  |  |  | 客户端发 SYN → 服务端回 SYN+ACK → 客户端再发 ACK | 简答 |

再补几条规则。

- 列的顺序随意，多余的列会被忽略。
- 空的选项格子会被跳过，不需要占位。
- CSV 支持 UTF-8（带不带 BOM 都行）和 GBK；字段里含逗号时记得用双引号包起来，Excel 导出时会自动处理好。
- 判断题的 A、B 两列可以留空，直接把「对 / 错」写进答案列。

如果不想拆成 A 到 D 四列，可以用一列装下所有选项，用竖线分隔，例如：

```
题目,选项,答案
下列属于面向对象三大特性的有？,封装|继承|多态|编译,ABC
```

## 六、DOCX 格式

Word 文档有两种写法，都能用，也可以混排。

第一种是正文段落，按 TXT 规则解析，每个字段一段：

```
1. 题干……

A. 选项一
B. 选项二
答案：B
```

第二种是表格，按 XLSX 规则解析，第一行当表头，一行一题。

两种写法同时存在时，以正文段落为准。表格只有在正文一段都没解析出题的时候才会启用，否则同一道题会被算两次。

两个必须知道的坑。

- 不要用 Word 的「自动编号」出题号。自动编号在 XML 里不在段落文字内，程序看到的是没有序号的行；手打 `1.` 或者干脆用空行分隔最保险。
- 标题后要空一行，否则标题会并进第一题题干，见第三节。

## 七、JSON / JSONL 格式

JSON 数组就是最外层一个方括号，里面每个对象一道题：

```json
[
  {
    "question": "下列属于面向对象三大特性的有？",
    "options": ["封装", "继承", "多态", "编译"],
    "answer": "ABC",
    "type": "multi",
    "analysis": "封装、继承、多态是三大特性"
  },
  {
    "question": "最低毕业学分是 81 学分。",
    "answer": ["对"]
  }
]
```

JSONL 是每行一个对象，没有最外层方括号：

```
{"question":"TCP 三次握手的第一步是？","options":["客户端发 SYN","服务端发 SYN","客户端发 ACK"],"answer":"A"}
{"question":"请简述三次握手。","answer":"SYN → SYN+ACK → ACK"}
```

字段别名如下，中英文都能认。

- **题干**：`question`、`stem`、`q`、`题目`、`题干`。
- **选项**：`options`、`choices`、`opts` 三个数组字段，或 `A` 到 `H` 独立字段。
- **答案**：`answer`、`answers`、`key`、`答案`，字符串或数组都行。
- **题型**：`type`、`题型`。
- **解析**：`analysis`、`explain`、`解析`。

`type` 的取值是 `single`、`multi`、`judge`、`fill`、`qa`，也认中文的单选、多选、判断、填空、简答。

从开源数据集转过来时注意两点。答案如果是数组，例如 `["A","C"]`，程序会自动拼成 `A|C` 再按字母还原；选项如果是对象，例如 `{"A": "封装"}`，请先转成数组。

## 八、题型是怎么判断的

不写题型时，按下面的顺序判断。

- 有 2 个及以上选项，答案是单个字母，判为单选题。
- 有 2 个及以上选项，答案是多个字母（`ABC`、`A,C`），判为多选题。
- 选项只有两项且是「对 / 错」「正确 / 错误」「√ / ×」，或者答案本身就是这些，判为判断题。
- 题干含 `____` 或 `（ ）` 且没有选项，判为填空题。
- 没有选项，答案是一段话，判为简答题。

想强制指定，加一行 `题型: 多选`，表格里就是「题型」列。可选值是单选、多选、判断、填空、简答，写英文 `single`、`multi`、`judge`、`fill`、`qa` 也认。

## 九、导入结果怎么读

导入完成会告诉你「成功 N 题、跳过 M 条」，并列出被跳过的行号和原因。

- **缺少答案** —— 该条没有解析到答案行或答案列，补上 `答案:`。
- **题干为空** —— 只有选项没有题干，补题干。
- **选项不足** —— 标了单选或多选，但只解析到 1 个选项，补选项或改题型。
- **答案字母找不到对应选项** —— 答案写了 `E` 但只有 A 到 D，检查答案。

导入是安全的。解析失败不会写入任何数据，也不会影响已有题库。

## 十、导入后怎么检查

1. 进「题库」页，找到刚导入的批次，点「预览」。
2. 预览是表格，每页 10 题，重点看三列：题型对不对、答案是不是原文而不是字母、题干有没有混进标题。
3. 有问题就改文件重新导入。新导入会生成新批次，不会覆盖旧的，旧的可以停用或删除。

## 十一、建议的书写顺序

1. 先用 [`题库模板.txt`](../Project/docs/templates/题库模板.txt) 抄一遍结构，改成自己的题。
2. 题目多了改用 Excel，用 [`题库模板.xlsx`](../Project/docs/templates/题库模板.xlsx)，一行一题，列名照抄。
3. 需要给同学分发时，另存为 `.csv` 或 `.docx`。
4. 导入后到「题库」页看一眼预览，确认题型和答案都对得上。
