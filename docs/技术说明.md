## 一、这是什么

一个**本地优先**的安卓屏幕搜题工具。核心流程：

```text
读屏幕文字 → 归一化 → 在自己导入的题库里做相似度匹配 → 悬浮层给答案
                ↓ 若识别题干没把握
         可选：把题干（或一张截图）交给 DeepSeek 处理
```

### 为什么默认不用「截屏 + OCR」

- **截屏 + OCR** —— 每次启动弹投屏授权、状态栏常驻投屏图标；OCR 还会引错字、丢格式。
- **无障碍读文本（默认）** —— 拿到的是结构化文本，不产生任何截图；也不会与其他程序抢占屏幕共享权限。
- **什么时候才用截屏 OCR** —— 只有题目本身是图片、或由 Canvas 自绘时。

## 三、代码地图

### `core/`（纯逻辑，可单测）

- `Settings.kt` —— 所有偏好项集中定义（取词方式、三档阈值、框体宽高、隐私开关、计价单价等）。
- `QuestionBank.kt` —— 题库数据模型（题、批次、启用状态、来源）。
- `BankParser.kt` —— 各格式解析：txt / csv / tsv / md 表格 / docx / xlsx / json / jsonl。
- `BankImporter.kt` —— 导入入口（选择文件 / 粘贴文本），20MB 上限与失败原因汇总。
- `BankStore.kt` —— 一批一个文件落盘；删批次就是删文件，启用状态跟着批次走。
- `BankBackup.kt` —— 导出/导入题库备份（JSON，含每批停用状态）。
- `OfficeReader.kt` —— docx/xlsx 的 OOXML 读取（zip + XML，20MB 上限）。
- `MatchEngine.kt` —— 匹配入口：归一化 + 候选排序。
- `Similarity.kt` —— 字符 n-gram 相似度打分（纯函数，单测覆盖）。
- `QuestionNormalizer.kt` —— 题干清洗：去题号、去页眉页脚、全角半角统一。
- `QuestionType.kt` —— 题型判定（单选/多选/判断/填空/简答）与答案文本拼装。
- `RegionSpec.kt` —— 选区比例编解码（跨屏宽一致，纯函数）。
- `DeepSeekClient.kt` —— 联网只走这里：`https://api.deepseek.com`，15s/90s 超时。
- `ApiKeyStore.kt` —— Key 存 AndroidKeyStore（AES-256-GCM），SharedPreferences 只放密文。
- `TierPolicy.kt` —— 「题库 / 文字 / 截图」三档分流决策。
- `UsageFormat.kt` —— 把 token 用量换算成金额的显示文本。
- `RecognizeHistory.kt` —— 最近 50 次识别记录。
- `SoundFx.kt` —— SoundPool 点击音效。
- `AppLog.kt` —— 内存环形日志（release 不写 logcat）。

### `overlay/`（悬浮层，纯 View + WindowManager）

- `OverlayService.kt` —— 前台服务：窗口生命周期、识别流程调度、通知。
- `OverlayWindows.kt` —— 窗口创建/定位/拖动/渐隐（`OverlayService` 的扩展函数）。
- `OverlayUi.kt` —— 自绘控件（圆钮、工具栏、答案小窗、确认卡）。
- `RegionSelectOverlay.kt` —— 选区遮罩。
- `ManualInputOverlay.kt` —— 手动输入框。

### `reader/` `capture/` `ocr/` `boot/`

- `ScreenTextReader.kt` —— 无障碍服务，读窗口文本节点；API 30+ 也支持 `takeScreenshot`。
- `ScreenCapture.kt` —— MediaProjection + ImageReader（截屏 OCR 模式）。
- `ImagePreprocess.kt` —— 截图裁剪与缩放，喂给 OCR 之前做预处理。
- `OcrEngine.kt` —— ML Kit 中文离线识别。
- `RestartReceiver.kt` —— 开机/更新后提示重新授权。

### 包根（应用骨架）

- `MainActivity.kt` —— 唯一的 Activity：权限申请、服务启停、Compose 宿主，实现 `AppHost`。
- `QSearchApp.kt` —— Application：启动时创建通知渠道（悬浮层前台服务要用）。

### `ui/`（Compose 界面）

- `AppUi.kt` —— 入口、主题（浅/深两套配色）、`LocalPal`。
- `Tabs.kt` —— 四个标签页：启动 / 识别 / 关于 / 题库。
- `Widgets.kt` —— 通用组件：分段控件、卡片、按钮、输入框、自绘提示、指示器。
- `Dialogs.kt` —— 六个弹窗：粘贴题库、格式说明、批次预览、查重、计价、识别历史。
- `AppToast.kt` —— 自绘提示条（不用系统 Toast）。
- `BankData.kt` —— 题库数据的 Compose 状态封装（IO 线程读取 + 防抖搜索）。
- `RegionPreview.kt` —— 框体预览的虚线框。
- `SecureWindow.kt` —— 给程序自己的弹窗挂 FLAG_SECURE。
- `AppHost.kt` —— Activity 与 Compose 之间的接口（权限状态、服务启停、设置读写）。
- `FirstRunPage.kt` —— 首启说明页。

## 四、识别链路

点一次「识别」之后发生了什么：

1. **取词**。
   - 无障碍 —— `ScreenTextReader` 读当前窗口的文本节点，按坐标拼成阅读顺序。
   - 截屏 —— `ScreenCapture` 抓一帧，交给 `OcrEngine`（ML Kit 中文）离线识别。
2. **清洗** —— `QuestionNormalizer`：去题号、去页眉页脚、全角半角统一、压缩空白。
3. **定位题干** —— 按「上边界 / 下边界」裁掉无关区域；有选区时按 `RegionSpec` 换算成像素再裁。
4. **匹配** —— `MatchEngine`：字符 n-gram 相似度（不是向量检索），对每个启用批次的每道题算分。
5. **分流** —— `TierPolicy`：
   - 一档（接近率 ≥ 阈值一）—— 直接返回题库答案，0 Token。
   - 二档（≥ 阈值二）—— 题干 + 本地前 3 条候选发给 DeepSeek 做对齐，少量 Token。
   - 三档（低于阈值二）—— 题干 + 一张截图，最多 Token（「发送内容」选了只发文字时仍只发文字）。
6. **展示** —— `OverlayService` 渲染答案小窗（题型、答案原文、耗时、token 与金额），同时记一条识别历史。

> 除第 5 步里的 DeepSeek 之外，其余步骤都在本机完成；纯本地模式不联网。

## 五、题库子系统

### 存储

- **一批一个文件** —— `filesDir/banks/<时间戳-序号>.json`，批次元信息（名称、来源、启用状态、题数）和题目放在同一个文件里。
- **删除以批次为单位** —— 删一个批次等于删一个文件，不会留下半批残留。

### 导入与解析

- **两个入口** —— 选择文件（可多选，一个文件一批）与粘贴文本。
- **解析范围** —— `txt` / `csv` / `tsv` / `md 表格` / `docx` / `xlsx` / `json` / `jsonl`；docx 与 xlsx 由 `OfficeReader` 直接读 OOXML（zip + XmlPullParser），没有引 Apache POI，所以安装包不会变大。
- **单条失败** —— 不会中断整批，失败原因汇总到导入结果里。

### 检索与去重

- **匹配** —— 归一化后的题干做字符 n-gram；题库改完下一次识别就生效，不用重启服务。
- **查重** —— 按归一化题干分组，每组可以「保留最早 / 保留最新」一键清理，也能逐条删。

### 答案呈现

- **只显示原文** —— 题库里答案写 `B`，界面显示 B 对应的选项文本；多选以顿号连接；判断题统一成「对 / 错」。
- **题型标签** —— `QuestionType` 按题干标注、选项数量与答案形态判成单选 / 多选 / 判断 / 填空 / 简答。

## 六、数据与隐私

数据都在应用私有目录里：

- **题库** —— `filesDir/banks/`，不加密（随应用沙箱，卸载即清空）。
- **设置** —— `SharedPreferences`（`qsearch_settings`），不加密。
- **API Key** —— `SharedPreferences` 只放 IV 与密文，密钥在 AndroidKeyStore；加密方式是 AES-256-GCM，密钥不可导出。
- **识别历史** —— `filesDir/history.json`（上限 50 条），不加密。
- **导出备份** —— 仅你主动点「导出题库备份」时写 `Download/香蕉做题题库`，不加密。

另外四条：

- **会往外发什么** —— 只有 `https://api.deepseek.com` 这一个出口；纯本地模式完全不联网。发什么由设置决定：只发文字（题干 + 前 3 条候选），或者文字 + 一张截图（`detail=low`）。
- **日志** —— release 包不写 logcat；内存里的环形日志最多 300 行，只在「关于」页本机查看。
- **防录制** —— 悬浮窗、手动输入框、选区遮罩、自绘弹窗都带 `FLAG_SECURE`；截屏 OCR 抓帧前先把悬浮层隐藏。
- **系统备份** —— `allowBackup=false`，云备份与设备迁移都排除全部数据域。

## 七、自行编译

需要 JDK 17 以上（本项目用 21）和 Android SDK。`ANDROID_HOME` 指向 SDK 即可，不必写 `local.properties`。

命令都要在 `Project/` 里执行：

```bash
./gradlew :app:assembleDebug        # 调试包
./gradlew :app:assembleRelease      # 正式包（没有 keystore.properties 时是未签名包）
./gradlew :app:testReleaseUnitTest  # 53 个单元测试
./gradlew :app:lintRelease          # 静态检查（CI 会跑）
```

注意事项：

- **templates 同步** —— `syncTemplates` 任务会把 `docs/templates` 里的「题库模板.*」复制进 `app/src/main/assets/templates`（不入库），`preBuild` 依赖它，模板只维护一份。
- **签名** —— `keystore.properties` 里的 `storeFile` 是相对工程根的路径；`.jks` 和口令都不入库，丢了就发不了更新。
- **版本号** —— 改了 `versionName` / `versionCode` 要加 `--rerun-tasks --no-configuration-cache`，否则 `packageRelease` 报 UP-TO-DATE，包里还是旧版本号。
- **dex 占用** —— `mergeDexRelease` 报「classes.dex 正在使用此文件」时，先 `./gradlew --stop`，再删 `app/build/intermediates/dex`。

## 八、已知限制与待办

- **包体 51.8 MB** —— 主要是内置的 ML Kit 中文 OCR 模型。开 R8 和资源压缩大约能减到一半，还没做。
- **文案没有外置** —— 界面文字都写在 Kotlin 里，没有 `strings.xml`，所以做不了多语言。
- **匹配只比字符** —— 不做语义理解。题干里混进页眉页脚时接近率会下降，可以用选区或裁剪边界避开。
- **高刷新率没验证** —— 120Hz 只在模拟器上跑过，模拟器确认不了，得真机试。
- **读不到的内容** —— Canvas 绘制的文字和纯图片题读不到，需要改用截屏 OCR。
