## 30 秒上手

- 下载 APK 安装，读完首启说明点「我已了解，开始使用」；
- 依次授权：悬浮窗、通知、无障碍服务；
- 「题库」页导入题库（没有题库先看 [题库书写规范](docs/题库书写规范.md)）
  - **或者**：获取 DeepSeek API Key，填入 API Key 后保存并测试连通即可；
- 「启动」页选「无障碍读文字」→ 点「启动」；
- 打开任意题目 → 点屏幕上的圆形按钮 → 点「识别」。

若需详细的图文讲解，详见 **[使用手册](docs/使用手册.md)**；若需自行编写题库，书写规范详见 **[题库书写规范](docs/题库书写规范.md)**。

## 三种搜索模式

在「启动」页的 **③ 搜索模式** 里切换，差别只在于题库和模型谁先上：

- **纯本地**：只在导入的题库里找答案，不联网、不消耗任何 Token，也不用填 API Key；
- **混合模式**：先查题库，有把握直接给答案（零 Token）；没把握才把题干 / 截图交给模型；
- **纯 DeepSeek**：题库完全不参与，每道题都问模型，适合题库里根本没有的科目。

默认是「纯本地」，装上就能用，不会有任何网络请求。

## 隐私

- **纯本地模式完全不联网**。只有混合模式和纯 DeepSeek 会请求 `api.deepseek.com`，没有别的服务器，也没有统计埋点；
- **API Key 加密存储**：用 Android Keystore 生成 AES-256-GCM 密钥，手机里只存密文，密钥不可导出；
- **题库和设置都在应用私有目录**，`allowBackup=false`，云备份和设备迁移都不会带走；
- **悬浮条、答案小窗、手动输入框、选区遮罩和所有弹窗都带 `FLAG_SECURE`**，录屏和系统截图里是黑块；程序自己截屏 OCR 前会先把浮层隐藏，抓完再恢复。

## 已知限制

- 无障碍读不到画布绘制的文字和纯图片题，这类请切截屏 OCR 模式（可能会因抢权限出问题，暂未测试，欢迎测试并反馈）；
- 部分定制系统会主动杀无障碍服务，需回系统设置重新开启；
- 仅 Android 8.0 及以上，未适配平板与横屏。
